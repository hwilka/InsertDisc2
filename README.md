# Insert Disc 2
A short experience I did in under 72 Hours for the Ludum Dare 60 game jam.

## Play it
You can play the game on [Itch.io in the browser](https://stratcat66.itch.io/insert-disc-2)

More information to the game can be found on [its Ludum Dare Page](https://ldjam.com/events/ludum-dare/60/insert-disc-2)

## Code Quality 
The code of the project was written in under 72 hours and is mostly a mess without comments.

## Engine
The game was written using the Godot Game Engine (Version 4.7.2), [which is licensed under teh MIT License](https://github.com/godotengine/godot/blob/master/LICENSE.txt)
